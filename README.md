# 📊 Sales Performance & Profitability Dashboard

## 📌 Overview
This project is an interactive Power BI dashboard analyzing sales performance, profitability, and trends.

## 🚀 Key Features
- KPI tracking (Sales, Profit, Orders, Margin)
- Top 10 states and products analysis
- Category-wise revenue distribution
- Monthly sales trend
- Sales vs Profit analysis
- Interactive slicers (State, Category, Date)

## 🧠 Key Insights
- California and New York drive highest sales
- Technology category contributes the most revenue
- Top products drive majority of total sales
- Sales show consistent growth over time

## 🛠 Tools Used
- Power BI
- Excel dataset
